WELCOME TO M27 BOOK!

M27 BOOK is a companion sportsbook for Madden 27 Franchise
Mode. Load your franchise save to explore game odds, player
props, parlays, betting challenges, achievements, statistics,
and more.

Each new sportsbook career starts with $150 in virtual
bankroll currency.

------------------------------------------------------------
1. INSTALLATION
------------------------------------------------------------

1. Download the M27 BOOK release package.

2. Extract the downloaded ZIP file if the package is provided
   as a ZIP archive.

3. Locate the M27 Sportsbook installer inside the extracted
   folder.

4. Run the installer and follow the on-screen instructions.

5. Once installation is complete, launch M27 BOOK from the
   installed application or its Start Menu/Desktop shortcut,
   if provided.

IMPORTANT:
Use the M27 Sportsbook installer for normal installation.
Do not use run.bat as the standard installation or launch
method.

------------------------------------------------------------
2. LOAD YOUR MADDEN FRANCHISE
------------------------------------------------------------

1. Launch M27 BOOK.

2. Select "Choose Franchise Save" or use the franchise
   import option.

3. Browse to your Madden 27 Franchise save file.

4. Select the save you want to use.

5. When prompted, create your sportsbook profile.

6. Once loaded, open Command Center, Games & Odds, or Player
   Props to begin exploring your franchise sportsbook.

Your sportsbook profile, bankroll, achievements, challenges,
and betting history are associated with the selected
franchise save. Switching to another franchise uses that
franchise's own sportsbook career.

------------------------------------------------------------
3. GETTING STARTED
------------------------------------------------------------

COMMAND CENTER
View the selected franchise week, game snapshot, bankroll,
betting performance, and market information.

GAMES & ODDS
Browse available game moneylines, point spreads, and totals.

PLAYER PROPS
Browse player markets, including passing, rushing, and
receiving props. Available markets depend on the loaded
franchise data.

BET SLIP
Add markets to your slip, adjust your wager, and place
straight bets or parlays using virtual currency.

ACTIVE BETS & BET HISTORY
Track unsettled wagers and review completed betting activity.
Available cash-out options depend on the wager and its state.

SOCIAL & SUGGESTED PARLAYS
Explore suggested combinations, trending bets, AI picks,
and community-style sportsbook features.

ECONOMY, CHALLENGES & ACHIEVEMENTS
Earn virtual currency through available activities, complete
challenges, and progress through sportsbook milestones.

SETTINGS
Customize the appearance and configure optional mobile
connectivity.

------------------------------------------------------------
4. OPTIONAL MOBILE COMPANION
------------------------------------------------------------

M27 BOOK can optionally connect to a phone through your
local network.

1. Launch M27 BOOK on your PC.
2. Open Settings.
3. Enable the phone connection.
4. Connect your phone and PC to the same Wi-Fi network.
5. Open the mobile address provided by the app on your phone.

If the connection does not work, check that both devices are
on the same network and that your PC firewall is not
blocking the connection.

Mobile setup is optional. You can use the desktop app without
connecting a phone.

------------------------------------------------------------
5. IMPORTANT NOTES & TROUBLESHOOTING
------------------------------------------------------------

FRANCHISE NOT LOADING
Make sure you selected the correct Madden 27 Franchise save.
If necessary, close the app and try importing the save again.

PLAYER PROPS OR MARKETS LOOK LIMITED
Available markets depend on the franchise data that can be
read. A franchise without usable historical player statistics
may use roster-based projections until more game data exists.

APP DOES NOT REFRESH AFTER A GAME
Use the app's Refresh Save option after saving or advancing
your franchise. If automatic refresh is enabled, make sure
the app is watching the correct Madden autosave file.

MOBILE CONNECTION FAILS
Confirm both devices are connected to the same Wi-Fi network
and check your firewall settings.

WINDOWS SECURITY WARNING
Windows may display a security warning for an application
that is not widely recognized. Only proceed if you trust the
source of the release and have verified the installer.

------------------------------------------------------------
6. SAVE SAFETY & VIRTUAL CURRENCY
------------------------------------------------------------

M27 BOOK is a companion application and is not a replacement
for Madden Franchise Mode.

Keep backup copies of important franchise saves as a
precaution.

The sportsbook uses fictional in-app currency. It does not
provide real-money gambling, real-money wagers, or payouts.
